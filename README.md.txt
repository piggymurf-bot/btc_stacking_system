# BTC Stacking Ensemble Trading System

This system ingests multi-source market data (On-Chain metrics, Derivatives/Funding Rates, and Technical Spot Price indicators), trains a domain-segmented stacking meta-learner with time-series splitting in the training process, and executes a vectorized backtest governed by RSI momentum filters and dynamic Average True Range (ATR) trailing stops.

---

The trading strategy uses out-of-fold probability predictions generated by a multi-domain stacking ensemble to take long spot positions while enforcing strict downside risk management.

## 3. Quantitative & Machine Learning Pipeline

### Data Ingestion & Feature Domains

The pipeline aggregates four distinct data streams to eliminate single-source bias:

1. **On-Chain Domain (`XGBoost`):** BGeometrics metrics including NVTS, MVRV-Z, Thermocap, Active Addresses, and Miner Reserves.
2. **Derivatives Domain (`LogisticRegression`):** Binance Vision metrics and CCXT aggregated funding rates tracking market leverage, open interest, and long/short liquidations.
3. **Technicals Domain (`LogisticRegression`):** Momentum indicators (RSI, MACD), moving average distance ratios, and spot volatility.

### Stacking Meta-Learner Architecture

* **Level-0 Domain Learners:** Specialized pipelines fit independently on domain feature subsets to prevent cross-domain feature noise.
* **Out-Of-Fold (OOF) Probability Generation:** Training via Time-series splitting and then generates out-of-fold probability vectors without data leakage.
* **Level-1 Meta-Learner (`LogisticRegression`):** Learns optimal weighting across base domain probabilities to output a calibrated unified probability prediction $P(y=1)$.

### Execution & Risk Rules (`src/backtest/engine.py`)

* **Combined Entry Signal:** Position entry requires $P(y=1) \ge 0.60$ AND Spot $\text{RSI}_{14} \le 65.0$ (filters out purchases at overbought local peaks).
* **Dynamic ATR Trailing Stop:** Sets a continuous trailing stop floor:

$$\text{Stop Price}_t = \text{Peak Price}_t - (0.8 \times \text{ATR}_{14, t-1})$$


* **Friction Modeling:** Every trade entry and exit incurs $0.08\%$ in combined exchange taker fees ($0.06\%$) and market slippage ($0.02\%$).

* Virtual environment tool (`venv` or `conda`)

## 5. Usage & Pipeline Execution

The system is controlled via `main.py` using CLI flags.

### End-to-End Execution (Download $\rightarrow$ Train $\rightarrow$ Backtest)

To run the full pipeline from raw data fetch to backtest generation:

```bash
python main.py --all --threshold 0.60

```

### Step-by-Step Modular Commands

1. **Download Data Only:**
```bash
python main.py --download

```


2. **Build Features & Purged Splits:**
```bash
python main.py --features

```


3. **Train Stacking Ensemble:**
```bash
python main.py --train

```


4. **Run Backtest Engine:**
```bash
python main.py --backtest --threshold 0.60

```

Running the backtest pipeline generates the following assets:

* **Predictions Matrix:** `data/processed/holdout_predictions.csv` containing actual close prices, target labels, and ensemble probabilities.
* **Trained Model Binary:** `models/stacking_ensemble.pkl` serialized model for live inference.
* **Equity Curve Visualization:** `data/processed/equity_curve.png` a two-panel chart displaying portfolio equity against the BTC benchmark along with active position states.
